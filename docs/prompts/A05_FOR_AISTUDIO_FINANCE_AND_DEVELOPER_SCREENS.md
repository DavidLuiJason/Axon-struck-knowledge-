SCREENS (use these exact titles and taglines; labels in sentence case):

1. LOAN CALCULATOR (id `loan-calculator`; engine loan.ts). Tagline: "See what a loan really costs". Fields: "Amount", "Yearly interest (%)", "Term" with a two-way choice Years or Months. Under Options: "Extra payment each month". The result (live, or on a "Calculate" button if the engine is slow): the monthly payment in very large type, then "Total interest" and "Total paid" rows, and with an extra payment "Months saved" and "Interest saved". A quiet row "Payment schedule" opens the first 12 rows (number, payment, principal, interest, balance) with "Show all"; a "Save schedule as CSV" button uses `src/services/saveFile.ts` the way other screens do. Engine limit messages shown as they are.
2. SPLIT AND TIP (id `split-bill`; engine splitTip.ts). Tagline: "Share the bill fairly". Field "Bill"; a row of tip choices 10%, 15%, 20% and "Other" (a number field); "People" with minus and plus buttons within the engine's limits. Under Options: "Round each share up" and "Uneven shares" (enter parts per person). The result: "Each person pays" in very large type, then Tip and Total rows, and the engine's one line about leftover cents when it applies.
3. PATTERN TESTER (id `pattern-tester`; engine patternTest.ts). Tagline: "Test a pattern against your text". Fields "Pattern" and "Test text"; the flags g, i, m, s, u, y as small switches in one row; the matches listed (position, text, groups) with the matched parts highlighted in the test text; an invalid pattern shows the engine's plain message. Under Options: "Replace with" and its result. One quiet line: "JavaScript flavour." Run the match inside a Web Worker created from an inline Blob and wrapped with the engine's `runWithTimeout` (1.5 seconds); on timeout show "This pattern took too long; it may backtrack badly." and terminate the worker; the screen must never freeze.
4. JSON AND DATA VIEWER (id `json-viewer`; engines jsonTokens.ts and jsonView.ts). Tagline: "Read and tidy JSON". A field to paste JSON and an "Open a file" button (limit from the engine, plain message). Two views switched by a two-way choice: "Tree" and "Text". Tree: collapsible rows built with the engine's `buildTree` and `childrenOf` windows (never render more than the engine's window at once; "Show more" per node), each row showing key, type and a short preview; tapping a row copies its path with a quiet "Path copied". Text: the reformatted text in a result box with Copy. Under Options: Pretty (2 spaces, 4 spaces, tab), Minify, Sort keys. A parse error shows the engine's message with line and column and scrolls the text field to it. A stats line (depth, values, size).
